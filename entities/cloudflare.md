# Cloudflare

Cloudflare (NYSE: NET) provides a global cloud platform spanning 330+ cities in 120+ countries. Its services include CDN, DDoS protection, DNS, Zero Trust, and edge computing.

## Platform Architecture

- **Global Anycast Network** — 248+ Tbps capacity
- Every request passes through Cloudflare's edge before reaching the origin
- **Unified Dashboard** — Single control plane for all products
- **API-first design** — All functionality accessible via REST API

## Product Families

- **Performance** — CDN, Argo, Stream, Images, Load Balancing
- **Security** — DDoS, WAF, Bot Management, SSL/TLS, Zero Trust
- **Developer Platform** — Workers, Pages, R2, D1, KV, Queues, AI
- **Network Services** — Magic Transit, Magic WAN, Spectrum
