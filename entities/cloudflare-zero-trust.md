# Cloudflare Zero Trust

Formerly Cloudflare for Teams. A comprehensive Secure Service Edge (SSE) platform combining Access, Gateway, and Tunnel.

## Components

- **Cloudflare Access** — Identity-aware proxy for internal apps
- **Cloudflare Gateway** — Secure web gateway with DNS, CASB, and DLP
- **Cloudflare Tunnel** — Secure outbound-only tunnels to origins
- **Cloudflare Browser Isolation** — Remote browser isolation for zero-trust browsing

## Key Capabilities

- Integrates with any OIDC/SAML identity provider
- Granular access policies based on user, device, location, and context
- **Device posture checks** — WARP client integration for device health verification
- Session logging and audit trails
- Split tunneling and traffic filtering
