# Cloudflare Pages

Pages is a platform for deploying static websites and frontend applications. It integrates directly with Git repositories and provides automatic builds and global deployment.

## Key Features

- Git-integrated CI/CD (GitHub, GitLab, GitLab)
- Automatic branch preview deployments
- **Pages Functions** — Serverless functions tied to specific routes
- Custom domains with automatic SSL
- Build plugins for popular frameworks (Next.js, Hugo, Jekyll, etc.)
- **Unlimited bandwidth** — No bandwidth charges
- **500 builds/month** on free plan
